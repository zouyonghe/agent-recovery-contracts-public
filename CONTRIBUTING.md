# Contributing to ReplayFence

Run `npm test` before submitting a change. Include a regression test for new behavior and keep protocol documentation aligned with implementation.

Do not commit credentials, personal environment configuration, machine paths, private run logs, or model-server settings. Use portable commands and synthetic data.

Explain service-contract changes separately from recovery-policy changes. Preserve failures and distinguish incomplete recovery from successful execution.
